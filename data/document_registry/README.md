# Document Registry
Kolom wajib: `document_id`, `title`, `drive_file_id`, `processing_status`.
Kolom tambahan: `original_filename`, `drive_url`, `publisher`, `publication_year`, `document_type`,
`category`, `subcategory`, `language`, `geographic_scope`, `description`, `keywords`, `access_level`.
Dokumen baru biasanya memakai status `pending`. Jangan unggah PDF sensitif ke GitHub.
